# TrendBT 回测结果（EMA20/50 + RSI-MA 突破策略，XAUUSD H1）

## 结论

- **策略**：XAUUSD H1。
  - 方向条件：EMA20 在 EMA50 之上，RSI-MA（RSI14 的 14 期均线）高于 55；做空相反，RSI-MA 低于 45。
  - 信号 K：之前至少连续 2 根回调；本身为阳线（做空为阴线），收盘突破前一根 K 的高点（做空为低点）。
  - 入场与出场：信号 K 收盘后，下一根 K 开盘按市价入场；止损放在“信号 K + 回调段”的极值，止盈 2R。
  - 时段与仓位：只做东京时间 08:00～23:00 开盘的信号 K；每笔风险为初始余额的 1%，同一时间只持有一笔。
- **2015～2026**（截至 10-23，周五平仓关）：
  - 1525 笔，胜率 33.2%，净期望 −0.026 R/笔，净盈利因子 0.96，净亏 39%；
  - 最大回撤约 88%（按初始余额计，相对资金高点约 83%），最多连续亏损 15 笔；
  - 扣成本前约为 0（毛 −7 R），亏损的 82% 来自隔夜利息和手续费。
- **年度表现起伏很大**（2026 年 +35 R，2025 年 −25 R），基本在随机波动范围之内，取决于行情性质，而不是信号本身。
- 诊断中发现的假设“止损 1.5～3 倍 ATR 的单子有优势”，在 2011～2014 年的样本外检验中**不合格**（A 组净盈利因子 0.94，合格线 1.3）。
- **最终结论**：这套规则在 2008～2026 年没有稳定的方向优势，不适合作为实盘策略；不再在这套规则上调整参数。

## 说明

策略源码：本文件夹的 `TrendBT.mq5`，是这些回测用的版本 **v1.2**，规则见源码开头的注释。它和回测时 FTMO_A 里编译的那份逐字节相同，UTF-16 编码（MetaEditor 的原生格式）。

各次回测的共同设置：

- FTMO-Server4，初始资金 100000 美元，参数全部默认（每笔风险 = 初始余额的 1%，盈亏比 2）。
- 测试器杠杆 1:100。黄金保证金比例 2，实际杠杆 1:50，和实盘账户一致。
- 手续费（每边 0.0007%）和隔夜利息已计入。

## 分析

- `trend_report.md`：前四次回测的汇总、测试器报告的回撤、按年份的表。
- `diag.md`、`diag2.md`：对 `trend_m1_fri0` 的诊断：
  - 成本拆分；
  - 按止损距离（美元、ATR 倍数）分组；
  - 2025、2026 年拆分；
  - 持仓时间、跳空、时段和大趋势；
  - 2026-10-22～23 的 K 线和交易。
- `oos_result.md`：预先登记的样本外检验。
  - 判定用 2011～2014 年开仓的交易。
  - 合格标准：A 组（1.5 ≤ 止损 ÷ ATR < 3）净盈利因子 ≥ 1.3，并且 B 组（< 1.5）净期望 < 0。
