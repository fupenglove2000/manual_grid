# TrendBT 回测结果（EMA20/50 + RSI-MA 突破策略，XAUUSD H1）

策略源码 TrendBT.mq5 v1.2（规则见源码开头的注释）。各次回测的共同设置：

- FTMO-Server4，初始资金 100000 美元，参数全部默认（每笔风险 = 初始余额的 1%，盈亏比 2）。
- 测试器杠杆 1:100。黄金保证金比例 2，实际杠杆 1:50，和实盘账户一致。
- 手续费（每边 0.0007%）和隔夜利息已计入。

每个文件夹里：

- `TrendBT_summary.txt`：EA 的汇总（UTF-16）；
- `TrendBT_trades.csv`：每笔交易；
- `<文件夹名>.htm`：测试器报告（UTF-16）；
- `agent.log`：测试日志，包括每个信号、日本时间和没开仓的原因。

`terminal.log`（含账号和登录 IP）和 `tester.log`（和 agent.log 重复）没有放进来。

## 分析

- `trend_report.md`：前四次回测的汇总、测试器报告的回撤、按年份的表。
- `diag.md`、`diag2.md`：对 `trend_m1_fri0` 的诊断：
  - 成本拆分；
  - 按止损距离（美元、ATR 倍数）分组；
  - 2025、2026 年拆分；
  - 持仓时间、跳空、时段和大趋势；
  - 2026-10-22～23 的 K 线和交易。
- `oos_result.md`：预先登记的样本外检验。
  - 判定用 2011～2014 年开仓的交易。
  - 合格标准：A 组（1.5 ≤ 止损 ÷ ATR < 3）净盈利因子 ≥ 1.3，并且 B 组（< 1.5）净期望 < 0。

## 结论

- 2015～2026 年扣成本前的毛 R 约为 0（1525 笔共 −7 R），净亏主要来自隔夜利息和手续费。
- 样本内找到的假设“止损 1.5～3 倍 ATR 的单子有优势”在样本外**不合格**：2011～2014 年 A 组 176 笔，净盈利因子 0.94；B 组 343 笔，−0.198 R/笔。
- 之后不再用这段数据调整参数或分组。
